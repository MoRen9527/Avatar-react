# Triavatar Registry Layer

## 作用

本目录承接 `TriavatarBusinessStrategyRegistry`、`TriavatarProductRegistry` 和 `TriavatarCodeRegistry` 的工作型资料。

## 真源优先级

1. `../../AGENTS.md`
2. `../../README.md`
3. `../../package.json`
4. 本目录中的登记文档

## 当前文件

- `business-state.md`：Triavatar 的商业定位、默认职责与边界
- `product-state.md`：Triavatar 的产品状态、模块职责与依赖
- `code-state.md`：Triavatar 的代码结构、健康状态与风险

## 更新规则

- 只有在用户明确要求“记录”或“更新”时才修改本目录。
- 对未来虚拟形象和游戏入口必须显式标记为规划中，除非代码已证明实现。
